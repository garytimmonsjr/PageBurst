# Taking the README screenshots

The README expects four images in this folder: `library.png`, `contents.png`, `series.png` and `reader.png`.

1. In the emulator, import the **Test Manga Library** folder (original test art, safe to show publicly).
   **Never use real manga pages or covers** in screenshots. That's copyrighted art, and it makes the app look like a piracy tool.
2. Open each screen:
   - `library.png`: the Library with the Continue Reading card
   - `contents.png`: the ☰ table of contents with a series expanded
   - `series.png`: a series page with its chapter list
   - `reader.png`: the reader with the top/bottom bars showing (tap the middle of the page)
3. Click the 📷 camera button in the emulator's side toolbar (or press Ctrl+S) to save a screenshot.
4. Rename the files to match the names above, drop them here, and delete this HOW-TO file.
